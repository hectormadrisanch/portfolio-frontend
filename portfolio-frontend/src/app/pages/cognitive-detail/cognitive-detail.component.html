Cognitive Stimulation Gaming Platform

Interactive web prototype designed to provide accessible and engaging cognitive exercises for user stimulation.

01. The Context

The objective was to create a frictionless, highly interactive environment where users could perform cognitive exercises through gamification. The core challenge was tracking student evolution and performance over time without disrupting the interactive client-side experience.

02. Architecture & Tech Stack

The platform relies on a heavy-client architecture, delegating complex interactions to the frontend while maintaining a lightweight analytics backend.

  • Game Engine (Frontend): Angular drives the entire SPA, managing the complex dynamic state, user interactions, and rendering of the cognitive exercises.
  • Analytics Tracking: A JSON-based backend implementation records statistical data, accurately tracking student performance and cognitive evolution across sessions.
  • Styling: Tailwind CSS utilized for rapid, utility-first UI component generation.
